# 油品价格维护

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 逻辑校验：`npx tsx scripts/verify-store.mjs`

多终端协同调价闭环，数据默认保存在浏览器 localStorage 中：

- **调价批次**：提交带修订号（每油品单调递增），批次带客户端幂等号；重复提交幂等去重。
- **价格时间轴**：同一油品同一生效时刻只留一份有效价；晚到价（修订号过期）、生效时刻撞车、旧窗口改动一律转冲突草稿，不覆盖生效版本。
- **冲突草稿**：可按最新修订号重新提交或丢弃，处理全程留痕。
- **班次交接**：离线交接包合并，两边都改过的字段并列保留，站长确认前不进入均价；确认后的拟调价走正常批次流程生效。
- **断点续传**：写入失败保留已写入条目的幂等键，重试从完整批次继续，不重复算差额。
- **失效重算**：价格一变动，未确认交接项失效并按新价重算差额；旧版本与原始差额在时间轴和审计页可查。
